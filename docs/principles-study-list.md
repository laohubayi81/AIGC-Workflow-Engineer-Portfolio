# 原理补课清单 · 面试防御（配合 ACTION_ITEMS.md 使用）

> **前提认知**：AI 辅助完成 ≠ 减分。Job 2（深圳 15-20K）把"熟练使用 AI 编程助手（Cursor/Claude Code）"写成**任职要求**。行业分水岭是：**能不能验证和解释 AI 的产出**。
> 你的 repo 已经是证明（benchmark 文化、偏差表、链接校验器），缺的只是原理层的"为什么"。
> **用法**：每个模块 = 你必须能脱口而出的问答。答案要点是骨架，展开讲 30-60 秒。**所有答案都用你自己 repo 的数字当论据**——这是别人做不到的。

## 一、扩散模型基础（4 问 · 半天）

**Q1 生成模型的基本原理是什么？**
要点：加噪→学去噪→从纯噪声逐步去噪即生成；**Latent Diffusion** = 在 VAE 压缩的潜空间做（省几十倍算力）；文本经 CLIP/T5 编码，cross-attention 注入。
你的论据：`768×768×3` 像素 vs 潜空间 `96×96×4`——这就是为什么 57.3s 单张是可行的。

**Q2 UNet 和 DiT 什么区别？**
要点：SD1.5/SDXL 用 UNet（卷积骨架）；SD3.5 起用 MMDiT（文本/图像 token 联合注意力）。Krea 2 / LTX / Wan / Flux **全是 DiT 家族**——你实测过的所有模型都是新架构，这是你的差异化。

**Q3 CFG 是什么？**
要点：Classifier-Free Guidance，有/无条件预测的差值放大——控制"听 prompt 的程度"。你的证据：Day 4 扫过 CFG 3/4/7；路线 B strength 0.6 vs 1.0 的取舍同理（控制强度 vs 自由度）。

**Q4 采样器和调度器是什么？**
要点：采样器=去噪步的数值解法（euler/euler_ancestral…），scheduler=噪声步长表（normal/karras）。你的论据：LTX distilled 8 步 vs RAW 28 步——蒸馏模型步数少就是这条路。

## 二、LoRA（5 问 · 半天）

**Q5 LoRA 为什么有效？**
要点：低秩分解 ΔW=BA，rank 越小参数越少；只训增量不动底模。你的论据：myface rank 32、体量 MB 级 vs 底模 GB 级。

**Q6 为什么能学到"人"？**
要点：少量图 + 触发词把"特定人脸特征"绑到词向量上。你的论据：39 张自拍、ohwx、无触发词泄漏 0.57 vs 基线 0.05——**泄漏=过拟合的直接证据**，能讲这个比背公式值钱。

**Q7 学习率/步数/rank 怎么定？**
要点：lr 过大发散过小欠拟合；步数不足不收敛过多过拟合；rank=容量。你的证据：1200 步 48min、Day 6 跳过 rank 对照的原因——说取舍不说数字崇拜。

**Q8 正则（prior preservation）干什么？**
要点：保留底模先验防"全家都像训练对象"。诚实说：你的配置没用正则、靠小数据集+低步数控制，这是已知取舍。

**Q9 怎么判断过拟合/欠拟合？**
要点：你的 2×2 矩阵（有/无触发词 × 有/无 LoRA）就是诊断工具——无触发词也出你=泄漏；有触发词不像=欠拟合。

## 三、ComfyUI / 工作流执行（4 问 · 半天）

**Q10 ComfyUI 怎么执行一张图？**
要点：DAG 拓扑排序，按依赖执行；模型按需加载、LRU 卸载。你的论据：前后端分离（UI JSON ≠ API Format）、`/prompt` 提交、`/history`/`/ws` 取进度。

**Q11 显存怎么管理？为什么分段？**
要点：模型权重驻留显存，多个大模型同 Queue 触发换入换出甚至 OOM。你的论据：14.2GB 峰值实测、Week 3 "LTX+ReActor+超分必须三段"的实测结论。

**Q12 UI JSON 和 API JSON 区别？**
要点：前者含画布坐标（前端用），后者是纯执行字典（后端用）。你的论据：`portrait_api.json` + ComfyClient。

**Q13 量化是什么？fp8/int8/gguf 差别？**
要点：权重降精度换显存/速度，代价是精度。你的论据：Krea 2 RAW FP8、LTX Q4_K_S GGUF、turbo NVFP4——三档量化你都跑过。

## 四、ControlNet / IP-Adapter / 深度（3 问 · 2 小时）

**Q14 ControlNet 原理？**
要点：底模副本 + zero-conv 注入条件（深度/姿态/边缘），结构控制。你的论据：Depth CN-LoRA strength 0.6/1.0 对比、Day 5"Depth 锁剪影、景别必须和 prompt 对齐"的实测教训。

**Q15 ControlNet / IP-Adapter / LoRA 边界？**
要点：ControlNet=结构条件，IP-Adapter=图像提示（身份/风格），LoRA=权重微调（ permanent 身份）。你的论据：Krea 2 无 IP-Adapter → Depth+Identity Edit 双路线的组件边界表。

**Q16 深度图怎么来的？**
要点：Depth Anything 类模型单目深度估计（ViT）。你的论据：VACE 动迁用它做逐帧控制、controlnet_aux 已实测。

## 五、视频链（4 问 · 2 小时）

**Q17 I2V 怎么工作？**
要点：首帧编码为 latent 起点 + 时序注意力 + 文本控制运动；音频可同 latent 空间联合生成（LTX 2.3）。你的论据：25f 热 20s/冷 70s、121f≈320s。

**Q18 换脸原理？**
要点：检测→对齐→inswapper 身份嵌入替换→贴回。你的论据：ReActor 逐帧、GFPGAN 下残所以 restore=none、Day 16/17 结论。

**Q19 RIFE 插帧原理？**
要点：光流中间帧估计。你的论据：24→48fps、58.3s 全链实测。

**Q20 为什么视频要分段？**
要点：多模型同队列显存换入换出/OOM。你的论据：Day 18 实测 + 三段架构 + 全链实验 JSON（待验证 OOM 边界）。

## 六、工程化（4 问 · 你的主场）

**Q21 批量队列怎么设计？**
要点：串行+状态持久化+失败重试+断点续跑。论据：CSV 50/50、skip=5 续跑。

**Q22 怎么保证不丢任务/可恢复？**
要点：state 落盘、幂等跳过。论据：`summarize_state` 回放 P50 与实测一致。

**Q23 单张成本怎么算的？**
要点：功率/租价折算到单张。论据：本地 0.006 元、AutoDL 0.035 元、RH 未实测按官网价——**口径意识就是答案**。

**Q24 超时/失败怎么处理？**
要点：指数退避、重试上限、失败隔离。论据：ComfyClient 实现。

## 七、AI 辅助协作本身（2 问 · 必考）

**Q25 "这些都是 AI 帮你做的吧？"**
答法（背下来）：*"是，工作流搭建和代码由 AI 辅助生成——所以我的价值不在打字，在三件事：**设计取舍**（为什么 Depth 锁构图而不是 IP-Adapter）、**验证闭环**（每个数字有 benchmark、失败进偏差表）、**成本意识**（单张 6 厘钱是算出来的）。AI 生成、我负责让它可信。"*

**Q26 "那原理你懂吗？"**
答法：**不要装懂**。按本清单逐项过，过到哪说到哪；没过的直说"这块我还在补，我的学习路径是 XXX"。面试官对"知道边界的人"容忍度远高于"背概念被拆穿的人"。
