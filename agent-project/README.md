# Agent 最小闭环

第 5 周核心：自然语言请求 → 参数 schema 校验 → 选择工作流 → 调用 ComfyUI API → 返回结果。v1 不做自动调参、复杂质量评估、自动重试。

第 2 周的 Python API 封装会先落在本模块。

## 核心功能

- 状态机 6 步（解析 / 校验 / 选工作流 / 调 API / 返回）
- 工作流注册表（JSON Schema）
- 批量任务 + 简单结果检查（文件存在、尺寸、是否有效）
