# 工作流

第 2–3 周核心：1 个 10+ 节点图像生产工作流，以及 1 个 15+ 节点视频生产流水线（换脸 / 超分 / 帧插值 / 时序一致性）。

## 核心功能

- 图像：批量输入 → 预处理 → ControlNet → LoRA → 生成 → 后处理 → 批量输出
- 视频：生成 → 一致性控制 → 换脸 → 超分 → 帧插值
- 每个工作流附 JSON、使用说明、效果预览和 benchmark
