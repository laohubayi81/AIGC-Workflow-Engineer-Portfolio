| | |
|---|---|
| 工作流 | `video-modules/LTX2.3_i2v.json` |
| 模型 | distilled 22B Q4_K_S GGUF + Gemma Q4 + video/audio VAE |
| 分辨率 / 帧 | 384×576，Length 25（约 1s @ 24fps），8 step，CFG 1 |
